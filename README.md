# Oakridge Construction

**Building Excellence. Creating Lasting Value.**

A premium, multi-page website for Oakridge Construction, a fictional South African construction company. Designed and developed by **Launch Point Digital** as a portfolio demonstration.

## Pages

- **Home** (`index.html`): hero, company introduction, key figures, services, featured projects, process, testimonials and accreditations
- **About** (`about.html`): company story, values, mission and vision, milestones timeline and leadership team
- **Services** (`services.html`): six service areas, sectors, process and FAQ
- **Projects** (`projects.html`): filterable portfolio, featured case study and key figures
- **Contact** (`contact.html`): enquiry form with validation, office locations and map

## Design

| Token | Colour |
| --- | --- |
| Charcoal black | `#1C1C1C` |
| Bronze gold | `#B58B52` |
| Warm ivory | `#F5F2EB` |
| White | `#FFFFFF` |

Typography pairs **Cormorant Garamond** (editorial headings) with **Manrope** (body text). The site uses smooth scrolling, scroll-triggered reveals, image wipes, animated counters and subtle hover states, and respects `prefers-reduced-motion`.

## Tech

Plain HTML, CSS and JavaScript, with no build step and no dependencies.

```
assets/
  css/styles.css
  js/main.js
  img/favicon.svg
```

To view it, open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages.
